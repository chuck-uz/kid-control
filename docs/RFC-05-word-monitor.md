# RFC-05 — Монитор контента: плохие слова + взрослый контент

Статус: **принят к реализации** (согласовано в grilling-сессии).
Область: агент отслеживает, что ребёнок **вводит** (клавиатура) и **смотрит** (окно/URL),
сопоставляет с управляемыми списками, и при совпадении **мгновенно** шлёт родителю алерт
со скриншотом в Telegram.

---

## 1. Контекст и цель

KidControl уже умеет: интервалы игра/отдых, ночную блокировку, удалённый скриншот/аудио,
алерты о ночных попытках (агент ставит поле в heartbeat → бэкенд → Telegram, с дедупом).
Перехвата ввода и слежения за окнами/URL — нет.

**Цель:** родитель получает мгновенный алерт со скриншотом, когда ребёнок печатает мат/
взрослые запросы или заходит на порно/эротика-домены — не подходя к ПК.

### Не-цели (сейчас)
- **OCR / анализ картинок (NSFW по изображению).** Только текст: клавиатура + заголовок
  окна + URL. Порно на нейтральном домене или в видео/картинке без узнаваемого URL —
  осознанно не ловим (отдельный тяжёлый этап при необходимости).
- **Полный кейлог.** Сырой ввод не хранится и не передаётся — только совпадения.
- **Стелс / обход антивируса.** Компонент не прячется (см. §8).

## 2. Ключевые решения (итоги grilling)

| # | Решение | Выбор |
|---|---------|-------|
| 1 | Источники | **A** клавиатура (`WH_KEYBOARD_LL`) + **B** окно/URL. OCR — нет |
| 2 | Данные | **Только совпадения**; сырой ввод/буфер нигде не хранится |
| 3 | Списки | **Управляются на бэкенде** (БД), едут на агента в снапшоте политики |
| 4 | Сопоставление | **Нормализация + подстрока**, уклон в полноту; домены — по хосту |
| 5 | Доставка | **Мгновенный пуш** агент→`/agent/alert`→Telegram (1–2 сек) |
| 6 | Контент алерта | устройство, категория, совпадение, источник, **контекст ±30** (настр.), время, **скриншот** |
| 7 | Антиспам | кулдаун 60 с на (категория+совпадение+источник) + потолок 10/мин со сворачиванием |
| 8 | Хранение | **метаданные без контента** (для timeline/счётчиков в панели); контекст+скриншот только в Telegram |
| 9 | Включение | тумблер per-device, **по умолчанию ВКЛ**; любая сессия; **тихо** (без индикатора) |
| 10 | Взрослый контент | списки **доменов (по хосту)** + **ключевых слов (18+)**, категория «🔞» |
| 11 | AV | **без стелса**: документированное исключение Defender + самовосстановление хука |
| 12 | Источник списков | **файл на VM** → импорт в БД + разовый админ-импорт (не в публичный git) |

## 3. Категории и списки

Четыре управляемых с бэкенда набора (+ исключения):

| Список | Матч | Источники | Категория |
|--------|------|-----------|-----------|
| Мат (`profanity`) | нормализация + подстрока | A + B | 🤬 Плохое слово |
| Взрослые слова (`adult_keywords`) | нормализация + подстрока | A + B | 🔞 Взрослый контент |
| Взрослые домены (`adult_domains`) | по хосту (суффикс) | B (URL) | 🔞 Взрослый контент |
| Исключения (`exceptions`) | нормализация | — | гасит ложные |

Приоритет при нескольких совпадениях: adult-домен → adult-слово → мат (первое найденное).

## 4. Матчинг (чистая логика, `KidControl.Domain.Monitoring`, TDD)

- **`TextNormalizer.Normalize`** — нижний регистр; `ё→е`; разворот частого leet/транслита
  (`0→о, 3→е, 4→а, o→о, e→е, a→а, p→р, c→с, x→х, y→у, k→к, …`); схлопывание повторов
  (`бляяя→бля`); удаление всех не-букв/цифр (пробелы, точки, дефисы между буквами исчезают,
  чтобы ловить `с.у.к.а` / `с у к а`). Уклон в полноту — межсловные ложные срабатывания
  осознанно принимаем и гасим `exceptions`.
- **`TermSet`** — компилированный набор нормализованных терминов; `TryMatch(normalized, out term)`
  (подстрока). Пустые/битые термины отбрасываются.
- **`HostSet`** — домены; `TryMatch(host, out domain)` по суффиксу (`www.pornhub.com` →
  `pornhub.com`). `HostSet.HostOf(url)` вытаскивает хост из URL.
- **`ContentMonitor`** — держит скомпилированные наборы + исключения; API:
  - `ScanText(text, source, context)` — adult-слова, затем мат; совпадение подавляется,
    если его перекрывает термин из `exceptions`.
  - `ScanUrl(url)` — хост против adult-доменов (→ 🔞/Url), плюс adult/мат-слова по строке URL.
  Возвращает `MonitorHit?` = (категория, термин, источник, контекст).

**Контекст** для клавиатуры — «хвост» сырого скользящего буфера (совпадение случается в
конце набора), для окна/URL — сам заголовок/URL. Позиции после нормализации не
восстанавливаем — это и не нужно.

## 5. Агент (Stage 3, `net8.0-windows`)

- **`UiHost`** (сессия пользователя): `WH_KEYBOARD_LL` → нормализованное скользящее окно
  (~64 симв., в памяти) → `ContentMonitor.ScanText` на каждый keystroke; после совпадения
  буфер очищается. WinEvent на смену фокуса окна (иначе опрос ~2 с): заголовок + URL
  (UIA для Chrome/Edge/Firefox, фолбэк на заголовок) → `ScanText`/`ScanUrl`.
- Хук **самовосстанавливается** (Windows сбрасывает LL-хук при зависании/переключении).
- Совпадение → IPC в службу (новый тип `UiCommand`) → служба снимает скриншот (уже умеем)
  и POST-ит `/agent/alert`.

## 6. Бэкенд (Stage 2, `net8.0`, деплой сразу)

- **Политика**: `WordMonitorEnabled` (default **true**), `ContextChars` (default 30), плюс
  доставка 4 списков на агента (в `PolicyDto`/снапшоте; версия бампается при изменении).
- **`/agent/alert`** (bearer): принимает {категория, термин, источник, контекст, скриншот}
  → дедуп (60 с на ключ) + потолок 10/мин со сворачиванием → Telegram-пуш со скриншотом →
  запись метаданных.
- **`word_alert`** (метаданные): device_id, category, term, source, at. Для timeline/
  счётчиков в веб-панели.
- **Сидинг списков**: файл на VM → импорт в пустую БД; разовый админ-импорт по `X-Admin-Key`.

## 7. Управление

- Бот: кнопка «🛡️ Монитор» (вкл/выкл) в меню ⚙️; строка «🛡️ Монитор: вкл/выкл» в 📊 Статусе.
- Веб-панель: timeline/счётчики алертов (позже).

## 8. Безопасность, приватность, этика

- Только совпадения; сырой ввод не хранится/не передаётся. Пароль всплыл бы только если сам
  является плохим словом (абсурд) — но и тогда лишь в контексте ±30, только в Telegram.
- Метаданные без контента на бэкенде; контекст и скриншоты — только в приватном Telegram.
- **Без стелса.** Возможный флаг Defender закрываем документированным исключением папки
  агента (в `deploy.bat`/доке). Хук не маскируется.
- Наблюдение за несовершеннолетним на **своём** ПК, с согласия родителя-владельца. Режим
  тихий — выбор родителя (см. решение №9).
